# Customer Churn Prediction — Nigerian Fintech

A machine learning project predicting customer churn for a Nigerian fintech company.

## Models Used
- Logistic Regression (AUC: 0.948)
- Decision Tree

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Seaborn

## Key Findings
- 12% churn rate across 1,000 customers
- Top churn drivers: low tenure, high support calls, no savings plan
